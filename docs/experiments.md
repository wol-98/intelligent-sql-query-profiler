## M16.2 — Composite Index Column-Order Evaluation

### Objective

M16.2 experimentally evaluates whether the ordering of columns within a
composite B-tree index affects query performance.

The experiments compare two controlled variants of the same composite
candidate:

1. Original column ordering generated by the M15 query-pattern-aware
   candidate generator.
2. Alternative column ordering generated by reversing the original order.

The same query, database environment, and baseline are used for both
variants.

No permanent indexes are created by these experiments.

### Experimental Scope

Four composite recommendations were selected for controlled column-order
experiments:

| Recommendation | Original Order | Alternative Order |
|---|---|---|
| Rec32 | `customer_id, status` | `status, customer_id` |
| Rec33 | `order_date, total_amount` | `total_amount, order_date` |
| Rec34 | `status, customer_id` | `customer_id, status` |
| Rec35 | `segment, customer_id, name` | `name, customer_id, segment` |

The experiments use the M16.2 evaluator with controlled temporary indexes.
Each temporary index is removed after its experiment.
